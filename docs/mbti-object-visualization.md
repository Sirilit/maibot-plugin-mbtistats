# 16 人格物件分布图（待美术合作）

目标：把现在“只有 5 个人格全身图”的展示，换成 16 个人格代表物件在 2D 平面上的分布图。物件数量按真实统计比例变化，中心显示本次数量前三的人格。

## 视觉

- 16 类物件各自有一个代表物，例如：
  - INTP：小锥形瓶
  - INFP：小蝴蝶
  - ESTP：小墨镜
  - 其余 13 类待定，优先选小尺寸、轮廓清楚、容易在密集排布里区分的物件。
- 物件在画面里密集但自然地排布，密度均匀，不要整齐网格；同类物件可以有小幅旋转/缩放变化。
- 每类物件的数量与本次统计人数成正比；总数太多时按比例缩放，保持画面密度稳定。
- 区域中心放一段文字：

  ```text
  本次统计数量前三的人格：
  #1 INFP
  #2 ESTP
  #3 INTP
  ```

  前三名从本次统计结果实时计算；并列时按类型代码排序，保证稳定。

## 素材要求

- 16 个透明背景 PNG 或 SVG，统一视角/描边/光照风格。
- 建议每个物件给 2–3 个尺寸档，或至少保证缩小到 24–32px 仍可辨认。
- 颜色不要和背景、中心文字抢；如果物件本身颜色很跳，需要一套降饱和版本。
- 素材名用类型代码：`INTP.png`、`INFP.png`……方便按统计结果直接取。

## 实现边界

- 这一步只做素材和布局方案；统计逻辑、历史快照、ECharts 趋势图保持不动。
- 新的分布图可以作为现有看板里的一个区块替换掉 5 张全身图；不改变 `mbti_stats` 返回图片的接口。
- 布局算法要可复现：同一份统计数据和同一个随机种子得到同一张图，方便测试和对比。
